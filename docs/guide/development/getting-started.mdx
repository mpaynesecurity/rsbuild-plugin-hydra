## Start the local development server

:::warning
HMR does not work properly due to a known bug between Bun and the Rsbuild HMR websocket.
```bash
# HMR Does not work
bunx --bun rsbuild
````

Use the Node runtime during development
```bash
rsbuild
````
:::
