### Known Bugs/Issues
:::warning
HMR does not work properly due to a known bug between Bun and the Rsbuild HMR websocket.
```bash
# HMR Does not work
bunx --bun rsbuild
````
:::

### Workarounds

##### Use the  Node runtime

```bash
rsbuild dev
```

##### Upgrade Bun to the `canary` version

```bash
bun upgrade --canary
```

now you can run

```bash
bun --bun rsbuild dev
```
